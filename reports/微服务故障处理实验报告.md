# 微服务故障处理实验报告

## 一、实验目标
1. 验证单个依赖服务 **被关停** 时，调用方返回预设提示而非崩溃，其他服务不随之宕机。
2. 验证单个依赖服务 **被注入延迟** 时，是否触发 **超时返回**。
3. 验证持续故障时是否触发 **熔断**（快速失败，不再反复请求故障服务）。
4. 验证对高频接口的 **限流** 是否生效（返回 `429 RATE_LIMITED`）。

## 二、故障注入方法
### 2.1 服务关停
```powershell
docker compose -f compose.microservices.yml stop <service>
# 恢复
docker compose -f compose.microservices.yml start <service>
```
### 2.2 延迟注入（Pumba）
```powershell
# 给 <service> 注入 4 秒延迟、持续 60 秒（>3s 读超时，用于触发超时返回）
docker run --rm -v /var/run/docker.sock:/var/run/docker.sock `
  gaiaadm/pumba netem --duration 60s delay --time 4000 <service>
```
