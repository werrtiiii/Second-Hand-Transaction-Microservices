## 后续启动注意

本次只通过docker compose start恢复服务，没有运行会创建新账号和交易的smoke脚本。保留当前数据的日常停止/启动可使用：

```powershell
cd D:\OneDrive\Desktop\Second-Hand-Transaction-Microservices
docker compose -f compose.microservices.yml stop
docker compose -f compose.microservices.yml start
```

不要执行down -v；它会删除数据卷。deploy-microservices-local.ps1默认会运行三条冒烟流程并新增测试数据，不能把它当成单纯启动命令。
