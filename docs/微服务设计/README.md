| 文件 | 用途 |

运行当前边界检查：

```powershell
python -B scripts/check-service-boundaries.py
```

该检查验证服务源码边界、数据表归属和迁移 Schema；接口行为与业务流程结果以 `reports/microservices-test-report.md` 为准。
