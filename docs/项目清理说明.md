# 项目清理说明

清理日期：2026-08-29

本仓库已移除与拆分后微服务构建、测试和运行无关的旧单体内容及可重建产物。

## 已移除

- 旧单体后端 `backend/`，以及旧 Compose、Kubernetes、启停和部署配置。
- 失效的旧单体 CI/CD 工作流、旧报告、阶段日志和重复交付包。
- 仅用于生成旧单体文档或打包旧交付材料的辅助脚本。
- Maven `target/`、前端 `node_modules/` 与 `dist/`、Python 缓存等可重建产物。
- 失败演练和旧导入产生的临时运行日志。

## 继续保留

- `services/` 三个业务微服务、`gateway/`、`platform/`、`frontend/`。
- 根 Maven 聚合构建、自动化测试和当前 CI/CD 配置。
- `compose.microservices.yml`、`deploy/microservices/`、`scripts/*microservices*` 等当前部署/回滚文件。
- `db/` 数据库初始化、迁移和权限脚本。
- 微服务划分图、接口清单、数据表归属、部署说明及当前测试报告。
- 最近一次成功覆盖导入的备份 `reports/local-runtime/data-import-20260828-191633/`，用于数据恢复。

## 重新生成依赖与产物

```powershell
npm --prefix frontend ci
mvn -B clean verify
```

也可直接重新构建并部署：

```powershell
.\scripts\deploy-microservices-local.ps1 -Version <版本号>
```
