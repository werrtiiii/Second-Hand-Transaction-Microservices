# 非 Docker 本地部署

## 运行结构

- 前端 Vite：http://127.0.0.1:5173
- 本地 Node API 网关：http://127.0.0.1:18080
- 用户服务：http://127.0.0.1:18081
- 商品服务：http://127.0.0.1:18082
- 交易服务：http://127.0.0.1:18083
- 本地 MySQL：127.0.0.1:3306

前端把 /api 和 /uploads 请求代理到本地 API 网关。网关根据
gateway/default.conf.template 中的同一份路由清单转发到三个服务。

## 前置条件

本机需要 Java 17 或更高版本、Maven、Node.js、npm、MySQL 8 和 mysql.exe。
项目根目录需要存在 .env，其中包含三个数据库密码和服务签名密钥。

## 第一次初始化数据库

以普通 PowerShell 运行：

    cd D:\OneDrive\Desktop\Second-Hand-Transaction-Microservices
    .\scripts\bootstrap-microservices-native-mysql.ps1

脚本会安全提示输入本地 MySQL root 密码，不会把管理员密码写入文件。
它创建以下独立数据库和最小权限账号，并按顺序执行 db 目录中的迁移：

| 服务 | 数据库 | 应用账号 |
| --- | --- | --- |
| user-service | secondhand_user | user_app |
| product-service | secondhand_product | product_app |
| trade-service | secondhand_trade | trade_app |

已有数据表时脚本不会覆盖或重复执行首次迁移。

## 启动

首次运行或代码有改动时：

    .\scripts\start-microservices-native.ps1 -Version local-native

已经完成后端构建和前端依赖安装时：

    .\scripts\start-microservices-native.ps1 -SkipBuild -SkipNpmInstall -Version local-native

启动脚本会检查端口、构建可执行 JAR、按需安装前端依赖、后台启动所有进程，
并等待三个就绪检查、网关和前端全部返回成功。

浏览器访问：http://127.0.0.1:5173/

## 查看状态、版本和日志

    .\scripts\status-microservices-native.ps1

版本接口：

    Invoke-RestMethod http://127.0.0.1:18081/actuator/info
    Invoke-RestMethod http://127.0.0.1:18082/actuator/info
    Invoke-RestMethod http://127.0.0.1:18083/actuator/info

运行日志位于 reports/local-native/logs。例如：

    Get-Content .\reports\local-native\logs\product-service.out.log -Tail 100 -Wait

## 停止

    .\scripts\stop-microservices-native.ps1

脚本仅停止本次本地部署记录的 Java 和 Node 进程，不会停止 MySQL 或 Kubernetes。
## 导入旧单体数据

先进行只读演练：

    python -B scripts\import_legacy_data_native.py <dump.sql>

确认 16 张业务表校验通过后执行覆盖导入：

    python -B scripts\import_legacy_data_native.py <dump.sql> --replace

脚本安全提示输入 MySQL 管理员密码，随后停止本地服务、备份三个数据库、在单个事务中替换业务数据、逐行比对原始值并重启服务。备份和 JSON 报告保存在 reports/local-native/data-import-时间戳。
### 双击启动

不要直接双击 ps1 文件，因为临时 PowerShell 窗口会在成功或报错后立即关闭。需要双击运行时，请使用：

    scripts\start-microservices-native.cmd

该启动器会绕过当前用户的脚本执行策略，并在结束后保留窗口以显示结果。停止时可双击 scripts\stop-microservices-native.cmd。
